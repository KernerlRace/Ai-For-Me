# Запись голоса для «Амадеуса» (macOS)

Спасибо, что помогаешь! Займёт примерно 25 минут: ~10 минут говоришь «Амадеус» по-разному, ~6 минут
читаешь короткие фразы с экрана и 10 минут просто записывается комната, пока ты занимаешься своими делами.

## Как запустить

1. Распакуй архив с этой папкой (например, в «Загрузки»).
2. Открой **Терминал**: `Cmd + Пробел`, набери «Терминал», Enter.
3. Набери `bash ` (с пробелом в конце), **перетащи в окно файл `record.sh`** из этой папки и нажми Enter.
4. Если появится окно установки инструментов разработчика — нажми «Установить», дождись конца и повтори шаг 3.
5. Когда macOS спросит, можно ли Терминалу пользоваться микрофоном, — нажми «Разрешить».

Дальше программа сама всё объясняет: спросит, как тебя подписать (одно слово латиницей), проверит
микрофон и покажет меню. Проще всего выбрать **4 — всё по очереди**.

## Что отправить

После каждой части на рабочем столе обновляется архив **`amadeus_<имя>.zip`** — в нём всё, что записано.
Его и пришли. Нужен перерыв — `Ctrl + C`, записанное не пропадёт; потом можно запустить снова и продолжить.

## Советы

- Говори как обычно, не старайся «чисто» — разные интонации и громкость как раз и нужны.
- Встроенный микрофон ноутбука подходит отлично. Наушники с микрофоном тоже можно.
- Пока пишется фон, пусть идёт обычная жизнь: видео, музыка, разговоры. Только без слова «Амадеус».

## Для меня: как добавить записи

Архив повторяет раскладку `data/`, его можно распаковать прямо туда — файлы подписаны её именем, а журнал
подсказок называется `prompts_<имя>.tsv`, так что мои записи и `prompts.tsv` не перезапишутся:

```powershell
Expand-Archive amadeus_anna.zip -DestinationPath data
```

Потом `python -m aiforme.wakeword.train`. Для отдельной тестовой сессии (другой день, другая комната)
подруга запускает `bash record.sh --split test`. Фразы в `phrases.txt` — команды из
`aiforme/voice_orchestrator/data/train.jsonl`; при изменении датасета их стоит выгрузить заново.
